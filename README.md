# ema-pe's archived scripts

This repository contains scripts that have been archived because they are no
longer in use. All scripts come from my [dotfiles
repository](https://gitlab.com/ema-pe/dotfiles), they're created here, once I
decide to archive them I move them to this repository.

The scripts are written in several languages, mainly Bash and Python. They are
self-documented, as the header of each script contains information about the
purpose of the script, how to use it, and the last commit where it can be found
on the dotfiles repository.

Note that a script is not currently guaranteed to work (e.g., there may be an
API change).
